## 第 0 章 · 项目速览

**安静陪伴（Aura Companion）** 是一个面向个人的情感陪伴类应用：能聊天、有情绪、会记住你、会说话、能换壁纸，数据全部留在本机。

| 项目 | 内容 |
|---|---|
| 类型 | 个人情感陪伴应用（IM 形态） |
| 当前版本 | **1.0.6** |
| 代码规模 | 后端 1 个 Flask 入口（26 KB）+ 前端 19 个 JS 模块 + 6 个 CSS 模块 |
| 四种形态 | 网页 / PWA / 桌面 Electron / 安卓 APK |
| 后端 | Flask（完全无状态） |
| 模型 | DeepSeek（可直连，也可经自建服务中转） |
| 语音 | edge-tts（微软晓伊）+ 系统 TTS 兜底 |
| 数据 | 全部存在设备本地（localStorage），不上云 |

**一句话概括架构**：前端是一份静态页面，后端只是"可选的中转与工具服务"——所以手机可以脱离电脑独立工作。

## 第 2 章 · 技术架构

### 2.1 三层结构

```
┌─────────────────────────────────────────────────────┐
│  表现层   templates/index.html + static/css (6)      │
│          19 个 JS 模块，无框架、无构建步骤            │
├─────────────────────────────────────────────────────┤
│  能力层   memory / mood / voice / weather / wallpaper │
│          chat / settings / updater / remote-config    │
├─────────────────────────────────────────────────────┤
│  服务层   Flask（无状态）：可选中转 + edge-tts + 发布 │
│          admin/ 后台管理（登录 + 远程配置 + 图标上传）│
└─────────────────────────────────────────────────────┘
                          ↓
              DeepSeek API（直连 或 经服务层）
```

**关键设计**：服务层是**可选**的。`aura_mode = direct` 时浏览器/WebView 直接调模型，密钥只存设备本地；`aura_mode = server` 时走自建服务（能拿到更好的朗读音色）。

## 第 4 章 · 界面与主题系统

### 4.1 设计语言

主设计语言是「**暖纸极简**」：衬线正文 + 暖纸底 + hairline 分隔 + 等宽元数据。
原则：**结构优于装饰**，单一锚点色，间距走 8 的倍数。

### 4.2 设计令牌（`app.css` 的 `:root`）

| 类别 | 令牌 | 说明 |
|---|---|---|
| 主色 | `--acc-h` `--acc-s` `--acc-l` | **三个数字拼出主色**，滑块/情绪色都改这三个 |
| 圆角 | `--r-bubble` `--r-card` `--r-input` `--r-thumb` | 统一圆角来源 |
| 缓动 | `--ease-soft` `--ease-slide` | 统一动画曲线 |
| 质感 | `--card-bg` `--card-line` `--sheen` `--bubble-*` | 卡片/气泡质感 |
| 柔光 | `--glow-a` `--glow-b` `--glow-scale` | 背景柔光强度 |
| 纹理 | `--grain` `--grain-opacity` | 极淡噪点，压色带 |

**明暗**：`body[data-theme="light"|"dark"]` 覆盖 `--bg/--surface/--bubble-me/--bubble-ai/--text/--line`。

### 4.3 柔和流动主题（本轮新增，可开关）

**定位**：不是换框架，是**在原有设计上叠一层可关闭的皮肤**。

| 项目 | 内容 |
|---|---|
| 风格 | 柔光渐变 + 大圆角 + 玻璃层 + 彩色渐变气泡（HeroUI 系） |
| 文件 | `static/css/theme-soft.css`（11 KB）· `static/js/theme-soft.js`（4.8 KB） |
| 作用域 | **全部 32 条规则锁在 `body[data-soft="1"]`**，不加该属性 = 零影响 |
| 开关 | 设置 → 外观 → 「柔和流动风格」 |
| 配色 | 设置 → 外观 → 「配色预设」：跟随主题色 / 紫 / 薄荷 / 暖橙 |
| API | `window.AuraSoft.{enable,disable,toggle,setPalette}` |

**改了哪些视觉**（只改质感，不动布局）：

| 元素 | 原版 | 柔和版 |
|---|---|---|
| 我的气泡 | 纯色 | 主色→主色+42° 渐变 + 白字 + 带色阴影 |
| 她的气泡 | 纯白 | 半透明玻璃 + backdrop blur |
| 输入栏 | 直角框 | 玻璃胶囊 + 主色光晕聚焦 |
| 发送按钮 | 灰按钮 | 渐变圆 + 悬停上浮 |
| 图标按钮 | 灰圈 | 圆形 + hover 光晕 |
| 背景柔光 | 微光 | 大而柔的双色光斑 |
| 圆角 | 18px | 20 / 18 / 22px |

**设计铁律（写死在 CSS 注释里）**：
1. 只用两个色相（主色 + 主色偏 55°），第三个就廉价
2. 阴影必须带色（`hsl(主色 …)`），纯黑阴影显脏
3. 渐变只给"我的气泡"和"发送按钮"
4. 圆角统一走 `--r-*` 令牌

### 4.4 主题相关的四个技术坑（已记录，勿重犯）

| # | 现象 | 真因 | 正解 |
|---|---|---|---|
| 1 | 渐变不生效、退回纯色 | `calc(var(--acc-l) - 8%)` 类型不匹配（无单位数字减百分比） | `calc(var(--acc-l) * 1% - 8%)` |
| 2 | 预设配色顶掉情绪色 | `--acc-h/s/l` 写在 **html 的 inline style** | 预设也写 html inline，CSS 只管衍生变量 |
| 3 | 覆盖不掉原样式 | `#log > .bubble.me` 等 id 选择器特异性高 | 用 `body[data-soft="1"] #log > .msg.me > .bubble` |
| 4 | 误判"没生效" | 同一脚本内"写 inline→读 computed"拿到旧值 | 分两次读 |

## 第 5 章 · 构建与部署

### 5.1 网页 / PWA

```bash
pip install -r requirements.txt
python app.py            # http://127.0.0.1:8000
```

PWA：浏览器访问 → 添加到主屏幕。Service Worker 由 `/service-worker.js` 下发，**版本号会被注入**（否则改了 CSS 浏览器不知道要更新）。

### 5.2 桌面（Electron）

```bash
cd desktop
npm install
npm run dist:win         # 产物：dist/安静陪伴-1.0.6-x64.exe
```

**打包结构**（关键）：`package.json` 的 `extraResources` 把 `../static`、`../templates`、`../icons`
复制到安装目录的 `resources/aura/` —— **不进 `app.asar`**，所以换 CSS/HTML 不用重打包，直接替换文件即可。

### 5.3 安卓（Capacitor）

```bash
python tools/build_web.py      # ① 同步前端到 web/
npx cap copy android           # ② 拷进 android 工程（不跑这步 = 打进去的是旧页面）
cd android && ./gradlew assembleDebug
```

**老坑提醒**：`cap add` 之后改的 CSS/JS **不会自动进包**，必须走上面 ①②③ 三步。

### 5.4 后台管理

```bash
python tools/launch.py admin     # 或双击「启动后台管理.bat」
```

能改：主题色 / 明暗 / 圆角 / 字号 / 柔光 / 纸墨 / 壁纸压暗、11 个功能开关、文案、快捷短语、桌面图标、危险操作、发布通道。
改完写入 `remote/config.json`（版本号 +1）→ App 每 30 秒轮询 → 热应用。

### 6.3 踩坑档案（10 条，按严重度排）

| # | 坑 | 后果 | 修法 |
|---|---|---|---|
| 1 | `waitress` 拒绝 `Connection: keep-alive`（逐跳头） | SSE 流式直接 500 | 去掉该头，WSGI 规范不允许 |
| 2 | 上游 SSE 没 charset | `requests` 按 ISO-8859-1 解码，**中文全乱码** | 显式 `upstream.encoding = "utf-8"` |
| 3 | `[hidden]{display:none}` 被 `#id{display:flex}` 干翻 | 该藏的更新条/图片行不藏 | `[hidden]{display:none !important}` |
| 4 | JS 构造函数定义了却没调用 | 人设下拉空、色板空 | 显式调用 `loadPersonas()` 等 |
| 5 | APK 里打的是旧前端 | 手机上看到老界面 | `build_web.py` → `cap copy` → 再打包 |
| 6 | SW 版本号写死 | 改了 CSS 浏览器不知道要更新 | 下发 SW 时注入真实版本号 |
| 7 | `updateBar` 变量声明未赋值（null） | **更新提示条永远弹不出来** | 初始化即赋值，selftest 防回归 |
| 8 | `py -3` 启动器指向失效解释器 | 探测能过、真合成 exit 101 | 用探测出的**真实解释器路径**再复核 |
| 9 | PowerShell `Invoke-WebRequest` 按 ANSI 发中文 | 发给本地服务的文字变 `??` | 中文请求一律用 Python `requests`（UTF-8） |

## 第 7 章 · 已知限制（规格书第 26 章，诚实说明）

1. **不替代专业帮助**：出现持续低落或自伤念头时，会给出心理援助热线（400-161-9995），但这不是医疗。
2. **记忆有上限**：摘要压缩会丢细节，长对话后早期细节可能变模糊。
3. **情绪是模拟的**：由规则 + 模型输出推断，不是真实情感状态。
4. **语音质量取决于网络**：edge-tts 需要联网，离线回落到系统 TTS（音色差）。
5. **数据不跨设备**：全部本地，换手机/换浏览器 = 从零开始（可用后台"导出配置"迁移外观，不迁移对话）。
6. **iOS 未覆盖**：需要 macOS 构建，未提供。
7. **APK 是 debug 签名**：自用足够，上架应用商店需要正式签名。
