## 四、w9 按性能类统一规则重判

信噪比 = 测量值 / 基线波动 = 30ms / 1300ms ≈ 0.023:1，远低于 5:1。
按规则：**任何基于墙钟的判定都不成立**（包括“通过”和“未通过”）。

结构性证据三条：

1. 波动线在首字渲染完成后 **200ms** 才启动（`chat.js` 里 `setTimeout(..., 200)`，代码可证）。
2. 单次执行实测 `maybe()` 0.6ms + 首帧 4.0ms（多次 0.3~0.6 / 4.3~4.8）。
3. 5 次墙钟中位数差：−332 / −160 / −122 / +22 / +202 ms —— 方向随机，无系统性变慢。

**w9 判通过。**

> 墙钟法在 ±1300ms 噪声下无法分辨 30ms，这是测量方法的边界，不是未通过。
